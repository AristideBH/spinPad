# Studio help

Studio lets you customize your SpinPad macropad: key bindings, RGB layers, encoder behavior, and icons.

## Getting started

1. Connect your SpinPad over USB.
2. Pick a layer in the sidebar and click a key to edit it.
3. Changes auto-save to the device.

## Undo / redo

Use the undo/redo buttons in the toolbar, or `Ctrl+Z` / `Ctrl+Y`.

## Need more?

Check the SpinPad website's docs for full coverage of layers, encoders, and macros.
